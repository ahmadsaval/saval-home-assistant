Keamanan: versi demo tidak menyalakan perangkat, tidak membuka CCTV, tidak memesan makanan, dan tidak memproses pembayaran. Jangan masukkan PIN, kata sandi, atau API key ke halaman ini.
Catatan: pengenalan suara browser dapat memerlukan koneksi internet dan izin mikrofon. Jika tidak berjalan dari file lokal, kita akan mencoba cara hosting gratis yang aman. AI ChatGPT dan kontrol perangkat nyata belum disambungkan pada versi ini.
